# Automated Lab Planner

## Use case & Functionality

A planner tool developed under and for the University of Antwerp.
The construction department has specific and complicated procedures that involve multiple steps.
This complicates the planning to use tools in the lab.
This planner is a fully stand-alone web application for planning lab experiments in an **automated** fashion.

The Lab planner has following functionality:
- Automatically plan experiment optimally according taking into account availability of lab and step durations
- Role based user access
- Material inventory
- Monitoring dashboard
- Automated alerts materials running low
